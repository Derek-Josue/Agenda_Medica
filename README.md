# Agenda_Medica
Agenda Médica
 
Sistema de escritorio para la administración de citas médicas, pacientes y especialidades.
 
Tecnologías utilizadas
 
- Lenguaje: C#
- Interfaz: Windows Forms
- Base de datos: MySQL

 
 Funcionalidades
 
Inicio de sesión con roles de usuario
Registro, modificación y eliminación de pacientes
 Gestión de citas médicas
Administración de especialidades
Visualización del historial de citas
 
Pasos para ejecutar
 
1. Abrir el archivo  Agenda_Medica.sln  en Visual Studio
2. Configurar la cadena de conexión a la base de datos MySQL
3. Ejecutar el script SQL para crear las tablas
4. Presionar el botón de Iniciar
